# SellSync - Retail Management Dashboard

A clean, responsive retail management dashboard built for the SellSync technical assessment.

## 🔗 Links
- **Live Demo:** https://your-vercel-link.vercel.app
- **GitHub:** https://github.com/francisyakubu563-lab/sellsync-dashboard

## 📸 Features Implemented

**1. Sidebar**
- Dashboard, Sales, Inventory, Reports, AI Insights, Settings

**2. Top Navigation**
- Search bar, Notification icon with indicator, User profile section

**3. Dashboard Summary Cards**
- Total Sales: ₦1,245,000
- Products: 328
- Low Stock: 12
- Today's Transactions: 86

**4. Sales Overview**
- Weekly bar chart (Monday - Sunday) using Recharts
- Values formatted in Naira

**5. Inventory Table**
- Columns: Product name, Category, Stock quantity, Price, Stock status
- Sample products: Indomie Noodles, Peak Milk, Dettol, Coca-Cola, Golden Penny, Close Up, Milo
- Status badges: In Stock / Low Stock / Out of Stock

**6. AI Insight Section**
- AI-generated business insight card: "Peak Milk is selling faster than usual this week. Consider restocking within the next 2 days..."
- Low stock alert card

## 🛠️ Tech Stack
- **React 18 + Vite**
- **Recharts** for charts
- **Lucide React** for icons
- **Pure CSS** - responsive grid, no heavy framework
